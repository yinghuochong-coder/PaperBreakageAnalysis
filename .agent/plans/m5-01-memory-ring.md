## 目的与可观察结果

在 `paperbreak_event` 中提供每路相机独立、固定槽位的内存环缓存。调用者能够按帧数或时长规划容量，在创建前校验帧池和内存预算；正常写入覆盖最旧帧；候选事件可获取闭区间窗口的只读租约，租约在环回绕、缓存关闭或对象销毁后仍保持所引用帧有效。快照输出容量、占用字节、实际缓存秒数、覆盖次数、活动租约和不足状态；不足状态变化通过有界同步通知交给上层报警桥接。

## 前置条件与假设

- 本任务无实体相机、MVS SDK 行为或硬件性能测试需求；测试使用内存构造帧和真实 `FrameBufferPool`。

- 环缓存登记发生在每相机保序预处理上下文；实现仍以互斥锁保护事件管理线程并发取租约，不依赖调用者额外同步。

## 设计说明

`MemoryRingPlanRequest` 支持 `duration` 和 `frame_count` 两种容量模式。时长模式使用 `ceil(seconds * fps) + safetyMargin`，并安全计算管线、后置窗口和并发事件所需帧池缓冲及字节预算；任何零值、非有限帧率、整数溢出、帧池不足或字节预算超限均返回 `SYS_CONFIG_INVALID`。

`MemoryRing` 在构造时一次性创建固定数量 `optional<FrameView>` 槽位。`push()` 只移动视图、更新 O(1) 元数据并在满载时覆盖最旧槽；错误相机、单调时间回退或非递增会话序号返回 `PIPELINE_FRAME_ORDER_VIOLATION`，关闭后返回明确状态。

`lease_window()` 在事件控制路径复制命中窗口的只读视图，像素缓冲继续共享相机对象池所有权。租约不可复制、可移动；共享租约状态记录活动租约数和总帧引用数，达到任一配置上限时返回 `EVENT_BUFFER_INCOMPLETE`，禁止无界增长。重叠租约的 `buffer_owner()` 指向同一原始帧缓冲，不复制像素。

窗口完整性采用单调时间闭区间 `[start, end]` 判断，并单独报告会话序号缺口。缓存关闭会清空环自身引用并拒绝新写入/租约；已发出租约继续有效，析构时确定性释放引用和计数。

不足通知是同步、无队列的轻量回调，只在不足状态发生变化时调用；异常被边界吞并并计数，不能破坏帧登记。首次填充不立即报警，环达到容量后仍无法覆盖规划的历史时长，或窗口租约不完整时进入不足状态。上层在后续服务接线中把状态映射到 `EVENT_BUFFER_INCOMPLETE` 报警。

### 线程和队列

本任务不新增工作线程或跨线程队列。`push()` 生产者为每相机预处理执行器，`lease_window()` 消费者为事件管理线程，二者通过每个环实例的短临界区同步。所有容器容量在构造时固定；租约的帧引用数量受 `maximum_leased_frame_references` 限制。

### 持久化与恢复

不适用。内存环和租约均为进程内易失状态，不写磁盘；持久化属于 M5-06/M5-07。

### 错误和降级

- `SYS_CONFIG_INVALID`：规划输入非法、算术溢出、帧池不足或内存预算超限；创建前拒绝。
- `PIPELINE_FRAME_ORDER_VIOLATION`：错误相机、时间回退或序号非递增；拒绝当前帧并保留旧环。
- `EVENT_BUFFER_INCOMPLETE`：窗口参数非法、缓存无可用帧或租约容量达到上限；不扩容，调用者保留可用证据/报警。
- 通知回调异常：捕获并计数，继续缓存；不从热路径传播异常。
