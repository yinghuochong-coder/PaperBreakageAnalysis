## 前置条件与假设

- 目标 MV-CS020-60GM 通过 GenICam 布尔节点 `ReverseX`、`ReverseY` 提供镜像功能。
- 无法访问实体相机；节点可用性和写后实际图像方向仍需硬件验证。

## 设计说明

配置使用 `reverseX`/`reverseY`，领域模型使用可选布尔参数并在能力模型中记录节点支持情况。启用设备不支持的镜像时返回既有 `CAMERA_CONFIG_FAILED`；关闭值允许通过，适配器对不支持的节点不写入，以兼容旧设备。支持节点仍参与暂停、写入、完整回读和失败回滚事务。

### 线程和队列

不适用。本任务不新增线程或跨线程队列。

### 持久化与恢复

沿用 config schema v2。新字段为可选布尔值，旧配置缺省为 `false`；下一次序列化后显式保存。配置写入继续使用既有原子替换、修订冲突和审计机制。

### 错误和降级

- 启用不支持的镜像：`CAMERA_CONFIG_FAILED`，参数标识为 `reverseX` 或 `reverseY`。
- MVS 节点读写失败：沿用 `CAMERA_PARAMETER_READ_FAILED`、`CAMERA_PARAMETER_WRITE_FAILED` 和事务回滚。
- 节点不存在且配置为关闭：忽略写入，实际快照不声明该节点。
