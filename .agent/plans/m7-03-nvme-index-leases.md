## 目的与可观察结果

NVMe v1 已提交块具备可删除重建的持久派生索引，可按相机和 UTC 时间窗定位；事件候选产生时建立有界租约，租约覆盖已提交块和随后提交的重叠块，容量回绕只删除未保护块；事件目录和 SQLite 元数据均成功提交后释放租约。查询结果给出按序块引用、跨块序号缺口/重叠以及提交时验证的 CRC32C 摘要，供事件和后续 M7-04 恢复流程追溯。

## 前置条件与假设

- 派生索引使用已批准的 SQLite3 依赖；数据库位于缓存根的内部元数据目录，块文件仍可独立扫描重建。
- 单调时间只用于当前进程的租约重叠判断，不写入持久索引；持久查询和租约记录使用 UTC 纳秒、块 ID 和序号。
- 当前没有实体相机和批准目标 NVMe；自动化测试使用小帧、临时目录、受控块存储和故障注入，不声称硬件性能或断电通过。
- M7-04 前生产块存储仍会在启动发现既有块时降级；本任务只提供重建入口，不执行启动扫描。

## 设计说明

`INvmeBlockIndex` 是可注入的派生索引边界。生产实现以 SQLite 严格表保存块摘要、活动租约和 `lease_blocks` 引用；内存中另保留当前进程单调时间范围，用于把随后提交的重叠块绑定到活动租约。登记块、建立/释放租约、选择/删除回收块均通过 NVMe 缓存的独立索引操作互斥串行化，不持有相机提交队列互斥量，因此 SQLite 和删除操作不会让相机提交路径等待磁盘 I/O。

块摘要记录路径、物理字节、相机、代次、UTC 起止、序号起止、帧数、块内缺口及头/索引/数据/尾 CRC。窗口查询按相机和 UTC 重叠筛选并按开始时间/代次排序，计算块内及跨块缺口、重叠和提交完整性；结果数量受调用上限约束。`rebuild` 只接收已由调用方验证的摘要并事务式替换派生块表；实际扫描器属于 M7-04。

事件运行时按每个来源候选 ID 建立一条覆盖所有已启用相机的租约。合并事件的各来源租约共同覆盖并集；冻结后记录所有来源租约 ID，只有事件目录提交、SQLite 元数据对账成功后才逐条释放。编码、准入、队列或持久化失败保留租约，避免把尚未可靠落盘的数据回绕删除；租约总数固定有上限，达到上限时返回稳定错误并继续内存事件链。

### 持久化与恢复

- 派生索引 schema 独立版本为 1，启用外键、WAL 和 `synchronous=FULL`；所有多表变更使用事务。
- 块发布成功后才登记；索引登记失败进入显式内存降级，绝不把未登记块作为可回收普通块。
- 事件租约先写租约行，再把当前重叠块写入引用表；未来块登记在同一事务中绑定活动范围。
- 释放租约删除引用和租约行；块只有零引用时可回收。
- `rebuild` 可事务式从已验证摘要重建块表并保留仍能解析的事件引用；扫描、校验和隔离由 M7-04 实现。
- SQLite 文件不是块存在或完整性的唯一证据；索引可删除并从块文件重建。

### 错误和降级

- 新增 `NVME_INDEX_FAILED`、`NVME_INDEX_QUERY_LIMIT`、`NVME_LEASE_CAPACITY`、`NVME_CACHE_PROTECTED`；SQLite 原始扩展码保留在诊断中。
- 所有块受保护或无可回收块时返回 `NVME_CACHE_PROTECTED`，普通滚动缓存进入内存降级，正式事件路径继续。
- 事件租约获取失败报告错误但不撤销已经建立的内存环事件；事件提交失败不释放租约。
- 查询超过结果上限返回稳定错误，不截断后伪称完整。

## 回滚与恢复

禁用 `rollingCacheEnabled` 可停止新块和新租约，不删除既有块、派生索引或事件数据。代码回滚前保留 `.pbnvme`、`.partial` 和索引数据库；不得为回滚删除用户缓存。派生索引损坏时保持块文件不动并降级，后续由 M7-04 有界扫描重建。任何 schema 回滚只可删除可重建索引副本，不得把索引删除当作块删除。

## 决策记录

- DEC-001：块文件继续是恢复事实来源；SQLite 只保存可删除重建的派生块/租约索引。
- DEC-002：持久索引不保存可跨重启误用的 `steady_clock` 数值；当前进程用内存单调范围，持久引用使用块 ID、UTC 和序号。
- DEC-003：事件提交失败保留租约，防止未可靠落盘证据被回绕；租约容量固定，避免无界保护。
- DEC-004：索引磁盘操作使用独立串行互斥，不持有相机提交队列互斥，避免磁盘延迟反压提交路径。

## 意外发现

- M7-02 只保留 `NvmeCommittedBlock` 路径和字节数，生产写入器尚未返回已计算的 CRC/序号摘要；M7-03 需扩展结果而不改变 v1 文件格式。
- 当前事件成功定义包含事件目录提交和 SQLite 元数据索引；租约必须晚于二者成功后释放，不能只在文件 rename 后释放。
- Visual Studio Debug 生成目录不能用 `--config Release` 代替 Release 预设；改用独立的 `local-windows-vs2026-release` 预设完成 Release 验证。
- 仓库级 `format-check` 仍被未修改的 `src/pipeline/include/paperbreak/pipeline/preview.hpp:6` 阻断；本任务所有 C++ 文件已单独通过同一 clang-format 的 `--dry-run --Werror`。
